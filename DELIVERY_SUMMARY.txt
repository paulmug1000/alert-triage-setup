================================================================================
DATA FLOW & PROCESSING
================================================================================

1. User opens app → Clicks "Alert Triage"
2. System checks discrepancy FLAGS in Automation Commander
3. For each client's master sheet:
   - Activates master switch (E2 = TRUE)
   - Double flushes (ensures calculations complete)
   - Reads InvComp/DirComp/CRMComp discrepancy columns
   - Collects all flagged rows
4. Fetches AIKnowledgeBase from Automation Commander
5. Stores alerts + knowledge base in Redis session
6. For each alert:
   a. Passes to Claude with context
   b. Claude analyzes & recommends
   c. Shows to user with progress
   d. User approves/rejects/investigates/refines
   e. Decision logged to TriageLog
7. Shows completion summary
8. (Future) Friday: Researcher Claude analyzes TriageLog for improvements
